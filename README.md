A deterministic logistic-saturation forecaster for week-one GTA VI trophy earn rates on Exophase: it fits a saturating curve to each trophy's rate history, shrinks unstable fits toward the tier mean, and reports honest asymmetric logit spreads that widen with horizon, fit error, and refresh jumps.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
